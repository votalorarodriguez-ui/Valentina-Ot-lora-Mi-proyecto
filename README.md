# Portafolio Web - Valentina Otálora

¡Bienvenido/a a mi portafolio web personal! Este proyecto fue desarrollado como parte de mi proceso de aprendizaje y formación en desarrollo web frontend dentro del programa **Jóvenes creaTIvos**.

##  Descripción del Proyecto

Este sitio web es un portafolio interactivo y adaptativo (*responsive*) diseñado para presentar mi perfil, mis habilidades técnicas, proyectos realizados y formas de contacto directo.

##  Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio web.
* **CSS3:** Estilos personalizados, paleta de colores, diseño adaptativo e interacciones visuales.
* **JavaScript:** Lógica interactiva para la navegación y componentes dinámicos.
* **Git & GitHub:** Control de versiones y alojamiento del código fuente.
